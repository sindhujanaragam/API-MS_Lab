# API & Micro Services Lab Programs

Programs organized by the 10 practices in the uploaded lab manual. Java classes detected in the manual are saved as separate `.java` files inside each practice folder. `extracted_code_reference.txt` preserves code/configuration-like lines for cross-checking against the manual.

## Before running
- These are lab-manual source extracts, not guaranteed to compile unchanged as one project.
- Each practice may need its own Spring Boot Maven project and dependencies.
- Some examples use in-memory collections, H2, Spring JDBC, Spring Data JPA, AOP, or SOAP dependencies.
- Open each practice folder and check its README/reference file.
